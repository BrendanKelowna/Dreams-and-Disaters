# Dreams and Disaters

This repository contains the source for the "Dreams and Disaters" project.

Overview
- HTML, CSS, and JavaScript files for the project UI and logic.

Getting started
1. Open the project folder in your editor.
2. Serve `index.html` with a static server or open it in a browser.

Files
- `index.html`, `nav.html`, `playerSheet.html`, `settings.html`
- `script.js`, `scriptHome.js`, `scriptSettings.js`
- `style.css`
